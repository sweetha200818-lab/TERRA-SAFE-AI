# TERRA SAFE AI
Complete beginner-friendly AI + GIS landslide risk prototype.

Features:
- Demo Login
- Dashboard
- AI Landslide Risk Prediction
- Interactive GIS-style map
- High/Moderate/Low risk zones
- Road risk panel
- Model performance
- FastAPI backend

Demo login: admin / terra123

Windows:
1. Open PowerShell in this folder.
2. py -m pip install -r requirements.txt
3. py -m uvicorn app:app --reload
4. Open http://127.0.0.1:8000

The included map uses demo locations. Replace them with validated real GIS/weather/sensor data before real-world use.
